# Student Request Prototype - Notes

**Related task:** T07
**File:** prototype/student-request.html
**Based on:** docs/wireframes.md (Screen 1 and Screen 2)

## What works
- Form with Student ID, Category, Description and Priority
- Error message when a required field is empty
- Confirmation screen with a request ID

## What is simulated
- The request ID is random and is not saved
- There is no database, no login and no email

## How to open
Download the file and open it in any web browser.
