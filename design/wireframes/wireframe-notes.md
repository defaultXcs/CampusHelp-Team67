## Screen 1: Request Form
Students enter their Student ID, choose a category and priority, write a description and click Submit. Empty required fields show an error message. (Requirements: FR1, FR2)

## Screen 2: Confirmation
After submitting, the student sees a success message and a unique request ID. (Requirement: FR3)

## Screen 3: Track Request
The student enters the request ID and sees the current status and the person assigned. (Requirements: FR4, FR6)

## Screen 4: Admin Dashboard
The administrator sees the number of open, ongoing and completed requests, a list of requests, and can assign a request or update its status. (Requirements: FR5, FR6, FR7)

## Note
These are low-detail wireframes. Real data and saving are simulated.
